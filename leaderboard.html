  • Pass^1 (Avg@3) is the average success rate over three trials. Pass^3 (Avg^3) is the share of tasks solved in all three trials, averaged over the ten domains. Both are in %; the bar shows Pass^3 solid and Pass^1 light. Drop is Pass^1 minus Pass^3: what the agent loses to inconsistency.
  • An episode fails if the user agent ends it with ###UNSATISFIED### before the task is complete.
  • Each user agent has its own ranking: scores are not comparable across user agents.
  • Pick a domain above the table to score every view on that domain alone; all domains averages the ten domains, each counting once.
  • Tokens are the agent's prompt plus completion tokens over every run (580 tasks × 3 trials), from the messages' usage. Cost is an estimate: those tokens at the model's list prices per million input and output tokens, as the runs were self-hosted and their spend is not recorded. Hover a cost for the prices used. The Pareto plots leave out models under 8B.
